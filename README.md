# FrostBound

An early Antarctic exploration game built with TypeScript, Three.js and Vite. Current source includes terrain, icebergs, a player controller and environmental rendering. The portfolio-project interactions described in the repository description are not implemented yet.

## Run locally

Use Node.js 22.12+ and npm:

```sh
npm ci
npm run dev
```

Open the URL printed by Vite. Click the game to engage pointer lock. Use W/A/S/D to move and the mouse to look. Escape releases the pointer.

```sh
npm run build
npm run preview
```

The production build is written to `dist/`. This is a prototype, with no published gameplay test suite or finished content progression.
